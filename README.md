# 月の異名あて（tsuki-imei）

旧暦の月と和風月名（睦月・如月・弥生・卯月・皐月・水無月・文月・葉月・長月・神無月・霜月・師走）を結ぶ1日5問の学習ゲーム。月の名前は書いて答え（かなでも正解）、正解したら名前の由来（よく言われる説）を選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/tsuki-imei/>

- 名前・読み・別の書き方・由来は、国立国会図書館「日本の暦」の「和風月名」のページ（<https://www.ndl.go.jp/koyomi/chapter3/s8.html>）に書いてあることだけです。
- 和風月名の由来には諸説あります。ゲームで出すのは、よく言われる説です。
- 旧暦の月の名前なので、いまの季節感とは1～2か月ほどずれがあります。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
